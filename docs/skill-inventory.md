## Routing constraints

- Use only the exact names in `AGENTS.md`; do not install the obsolete `frontend-design`, `frontend-skill`, `next-best-practices`, `shadcn`, or similarly named substitutes.
- Use `motion` only under the repository's free-Motion policy. Motion+ instructions, packages, APIs, source, and paid access are excluded.
- Use `portfolio-r3f-3d` only in the explicitly approved optional 3D phase and only after dependency approval.
- Fetch current `web-design-guidelines` rules only when network access is explicitly available; otherwise use a reviewed repository snapshot if one is approved later.
- Treat the computed hashes in `skills-lock.json` as the immutable fingerprints of installer-managed copies. A branch name such as `main` is not a reviewed revision by itself.
- Re-run source, license, script, shell-directive, and diff review before updating any skill. Never replace all skills from an upstream repository wholesale.
