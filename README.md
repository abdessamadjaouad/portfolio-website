# Abdessamad Jaouad portfolio

Phase 1 provides the reproducible Next.js foundation for Abdessamad Jaouad's portfolio. The current page is intentionally a neutral semantic shell; approved content and visual design belong to later reviewed phases.

## Prerequisites

- Node.js 24.19.0 (pinned in `.mise.toml`)
- npm 11.17.0 (pinned in `package.json`)

With [mise](https://mise.jdx.dev/) installed, run `mise install` from the repository root.

## Local development

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run check
```

See `AGENTS.md` and `portfolio-codex-implementation-plan.md` before making phase work.
